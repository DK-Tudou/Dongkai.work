# 董凯 · UI/UX 设计师作品集

React + Vite 单页作品集，围绕产品体验、企业级系统和设计体系展开。包含本地循环视频 Hero、个人经历、精选项目分类、设计能力卡片和整屏联系页。内容版心最大宽度为 1280px，并适配窄屏浏览。

## 本地预览

```bash
pnpm install
pnpm dev
```

生产构建与预览：

```bash
pnpm build
pnpm preview
```

头像、项目展示图、循环背景视频和简历 PDF 位于 `public/`。

## GitHub Pages

此仓库通过 GitHub Actions 自动构建并发布到 Pages。将变更推送到 `main` 后，可在仓库的 **Settings → Pages** 查看部署状态和访问地址。
